# What to download

`0-OPEN-DOWNLOAD-PAGES.cmd` (or `START-HERE.cmd`) opens every one of these pages for you.
Click Download on each, leave the files in your Downloads folder — the installer picks them
up from there automatically. Nothing needs to be moved or unzipped.

No addon files are shipped in this pack; they stay the creators' to distribute.

Checked on CurseForge **7 September 2026**. Latest released Bedrock version then: **26.45**.
Target line: **26.40**.

## Making Null and Verity actually run

Both are script-driven packs. What makes script packs fail on a newer game is not the version
tag, it's the **Beta APIs** experiment being off — so the setup turns it on for you by editing
the world's `level.dat` (backup taken first, file re-checked after). Verity states it needs
Beta APIs; Null was built in the same beta-script era, and turning the toggle on gives it its
best shot on 26.4x.

What that costs: **achievements are off in that world.** That's Verity's price, not a choice
the pack makes — no Bedrock world can have Beta APIs and achievements at once.

Null's file is still 26.20. Nobody can promise a four-drop-old script pack runs on 26.45, so
prove it before it touches the survival world: `8-HORROR-TEST-WORLD.cmd` on a brand-new
throwaway world. If Null shows up there, it will show up in the main world. If it doesn't,
`9-HORROR-OFF.cmd` takes it back out in one click and nothing else changes.

## Not included, and why

| Project | Reason |
|---------|--------|
| **Newb x Daydream** | On Windows it needs the Wyvern Loader / BetterRenderDragon — a patched Minecraft client, not a resource pack. Unbound Visuals gets the same look through the official pipeline. |
| **Actions & Stuff** | It's a paid Marketplace product by Oreville Studios. The "free .mcpack" sites mirroring it are piracy. Origin Animation is the free, CurseForge-hosted equivalent. (Buy A&S on the Marketplace if you want the real thing — it applies from the in-game pack menu.) |
| **Bare Bones & Stuff** | Excellent pack (26.40, 2.3M downloads) but it requires Actions & Stuff to work, so it inherits the problem above. |
| **Aqueous Depths** | Best-looking ocean overhaul, but its own page says **"VIBRANT VISUALS ARE NOT COMPATIBLE"** — it would cancel Beautiful Mode. Swap it in only if you drop Unbound Visuals. |
| **Gigantic Oceans** | Rewrites continent/ocean size — incompatible with an existing world and with Nature's Touch's biome rework. |
| **Expansive Biomes** | Requires experimental settings, last file May 2025, and warns it "may not work well with other biome addons". |
| **Better Trees** | Replaces vanilla trees at world-gen level — head-on collision with Nature's Touch. Pick one; Nature's Touch is the 26.40 one. |
| **Better Foliage** | Last file Nov 2025, tagged 1.21.120 and below. |
| **Bedrock Reimagined** | Big and well loved, but it does its own custom biome generation — conflicts with Nature's Touch. |
| **Animals nature** | Duplicate ambient-spawn system against Alex's Mobs. |
| **CMDBlocc's Vehicles / MineCars / Better Vehicles** | The other vehicle addons are all stale — newest files are Jan 2024 to May 2025, tagged 1.20.x–1.21.8x. Nuckem is the only one still being built for the 26.x line. |
| **Backpack Plus** | 1.3M downloads, but its newest file is tagged 26.30 and it does not state achievement safety. Better Backpacks is newer, 26.40, and explicitly achievements-friendly. |
| **Tonalli** | Author states it "is not yet 100% playable". |
