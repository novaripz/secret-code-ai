Subject: Your Minecraft setup - do these in order


Hey! Everything's ready. Takes about 20 minutes, most of it waiting on downloads.
You never have to touch a Minecraft folder - it's all double-click stuff.

This is Bedrock Edition (Minecraft for Windows), not Java.

The prettier version of these instructions, with every download link as a button:
https://claude.ai/code/artifact/500c7e63-506c-4eea-afc0-2c7308b9400c


DO THIS IN ORDER
----------------

1. Download the pack folder:
   https://github.com/novaripz/secret-code-ai/archive/refs/heads/claude/bedrock-streamer-pack-bs2c1j.zip
   Right-click the ZIP > Extract All. Open the "streamer-minecraft" folder inside.
   Put it somewhere you'll find again (Desktop is fine).

2. Open Minecraft once, open any world for a few seconds, then quit all the way out.
   (This creates the folders the setup writes into.)

3. Make the survival world you actually want to play in.
   In world settings turn ON: Multiplayer Game, and "Require players to accept
   resource packs". Then QUIT MINECRAFT COMPLETELY - this part matters, the game
   undoes the next step if it's still open.

4. Double-click START-HERE.cmd

5. It opens a bunch of download pages in your browser. Click the green Download
   button on each one. Leave every file in your Downloads folder - don't rename
   them, don't unzip them, don't move them.

6. Go back to the setup window and press Enter.
   It finds the files by itself, installs everything, switches it all on in your
   world, and offers to launch Minecraft. Say yes.

7. In game: Settings > Video > Graphics Mode > Vibrant Visuals
   That's the aurora, shooting stars and god rays. Only setting you change by hand.
   (If it's greyed out your GPU can't do it - not a problem, everything else works.)

8. Make a second junk world and run 8-HORROR-TEST-WORLD.cmd on it. Play a normal
   session. The Null horror addon shows up on its own - no commands. See below.

9. Friends join from Play > Friends while your world is open, and accept the
   download prompt. They install nothing - Minecraft sends them the addons.


TWO THINGS TO KNOW
------------------

* Achievements are OFF in this world. Verity needs Minecraft's "Beta APIs"
  setting, and no world can have that and achievements at once. That's Minecraft's
  rule, not something the pack chose. Tell me if you'd rather have achievements
  and I'll pull Verity out.

* Null is the one addon that might not work - its last release was built for an
  older Minecraft version. That's why step 8 tests it on a junk world first.
  If it's a dud, 9-HORROR-OFF.cmd removes it in one double-click and nothing
  else changes.


AFTER SETUP, THESE ARE THE ONLY BUTTONS
---------------------------------------

  3-BEAUTIFUL-MODE.cmd    full atmosphere
  4-PERFORMANCE-MODE.cmd  same addons, better FPS
  11-OPTIMIZE-STREAM.cmd  tunes the game for a steady 60 while live
  9-HORROR-OFF.cmd        panic button - removes Null, Verity, Stalkers
  5-BACKUP-WORLD.cmd      save a copy of the world right now
  6-RESTORE-BACKUP.cmd    put an old copy back
  1-CHECK-SETUP.cmd       shows what's installed and what's switched on

Close Minecraft before running any of them, start it again after. Every one takes
a backup first, so nothing you do is permanent.

IF SOMETHING LOOKS WRONG
------------------------
Run 1-CHECK-SETUP.cmd first. Nine times out of ten it's one of these:
  - Minecraft was open while a script ran  -> close it, run the script again
  - Wrong world picked from the list       -> run it again, pick the right one
  - Vibrant Visuals off                    -> Settings > Video > Graphics Mode

The docs folder has the full troubleshooting page, the compatibility notes and
the optimization guide.

All addon versions checked on CurseForge 7 September 2026. Everything downloads
from the creators' own pages - nothing is bundled or re-hosted.
