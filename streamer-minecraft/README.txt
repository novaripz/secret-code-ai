==========================================================
  MINECRAFT BEDROCK STREAMER PACK
  Download -> Install -> Launch Minecraft -> Play
==========================================================

You need: Minecraft Bedrock Edition (Minecraft for Windows) on Windows 10 or 11.
This is NOT Java Edition. No Forge, no Fabric, no .jar files, nothing to patch.


----------------------------------------------------------
FIRST TIME SETUP  (about 10 minutes, once)
----------------------------------------------------------

STEP 1 - Open Minecraft once
   Launch Minecraft for Windows, open any world for a few seconds, quit.
   (This creates the folders the setup needs.)

STEP 2 - Download the addons
   Open docs\DOWNLOAD-LIST.md and download the 7 files in the "Core set" table
   from their official CurseForge pages. Save every file into:

       addons\downloads\

   Don't rename them. Don't unzip them.

STEP 3 - Double-click  2-INSTALL-ADDONS.cmd
   It unpacks everything and installs it into Minecraft. It will list what it
   found. Nothing is switched on yet.

STEP 4 - Make your world in Minecraft
   Create the survival world you want to play in (or use one you already have).
   In world settings turn ON:  Multiplayer Game,  Require players to accept
   resource packs.  Then quit Minecraft completely.

STEP 5 - Double-click  3-BEAUTIFUL-MODE.cmd
   Pick your world from the list. It backs the world up, then switches all the
   addons on.

STEP 6 - Start Minecraft
   Settings -> Video -> Graphics Mode -> Vibrant Visuals.
   Open your world. Done.


----------------------------------------------------------
EVERY DAY
----------------------------------------------------------

   3-BEAUTIFUL-MODE.cmd     full atmosphere - aurora, shooting stars, god rays
   4-PERFORMANCE-MODE.cmd   same gameplay, atmosphere off, better FPS

   Close Minecraft first, run the file, pick the world, start Minecraft again.
   Takes about 20 seconds. Switch as often as you like, nothing is lost.
   In Performance Mode also set Video -> Graphics Mode back to Fancy.

   5-BACKUP-WORLD.cmd       save a copy of the world right now
   6-RESTORE-BACKUP.cmd     put an old copy back (undoable - it backs up first)
   1-CHECK-SETUP.cmd        tells you what's installed and what's on
   7-EXPORT-MCWORLD.cmd     make a .mcworld copy to send someone
   8-HORROR-TEST-WORLD.cmd  the Null horror addon - THROWAWAY WORLD ONLY


----------------------------------------------------------
FRIENDS
----------------------------------------------------------

Only you install anything. Friends just join your world from their Friends list
and accept the download prompt - Minecraft sends them the addons automatically.
Your world has to be open for them to join. Details in docs\MULTIPLAYER.md.


----------------------------------------------------------
BACKUPS
----------------------------------------------------------

Every mode switch and every restore takes an automatic backup into backups\.
The last 15 automatic ones are kept; ones you make yourself are kept forever.
Copy the backups\ folder to a USB stick or OneDrive now and then.


----------------------------------------------------------
WHEN SOMETHING GOES WRONG
----------------------------------------------------------

Run 1-CHECK-SETUP.cmd first, then read docs\TROUBLESHOOTING.md.
Almost everything is one of these three:
   - Minecraft was open while a script ran   -> close it and run the script again
   - The wrong world was picked from the list -> run it again, pick the right one
   - Vibrant Visuals is off                   -> Settings -> Video -> Graphics Mode
