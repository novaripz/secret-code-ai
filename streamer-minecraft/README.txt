==========================================================
  MINECRAFT BEDROCK STREAMER PACK
  Download -> Install -> Launch Minecraft -> Play
==========================================================

Minecraft Bedrock Edition (Minecraft for Windows), Windows 10 or 11.
Not Java. No Forge, no Fabric, no .jar files, nothing patched.


----------------------------------------------------------
SETUP - ONE FILE
----------------------------------------------------------

   1. Open Minecraft once, open any world for a few seconds, quit.
      (This creates the folders. Only ever needed once.)

   2. Make the world you want to play in, then quit Minecraft again.

   3. Double-click:   START-HERE.cmd

That's it. It opens every download page for you, waits while you click
Download on each one, finds the files in your Downloads folder by itself,
installs everything, switches it all on in your world, turns on the world
setting Verity and Null need, and offers to launch Minecraft.

In game: Settings -> Video -> Graphics Mode -> Vibrant Visuals.


----------------------------------------------------------
EVERY DAY
----------------------------------------------------------

   3-BEAUTIFUL-MODE.cmd     full atmosphere - aurora, shooting stars, fog
   4-PERFORMANCE-MODE.cmd   same addons, heavy atmosphere off, better FPS

   Close Minecraft, run the file, pick the world, start Minecraft. ~20 seconds.
   Switch as often as you like. Nothing is lost either way.
   In Performance Mode also set Graphics Mode back to Fancy.

   9-HORROR-OFF.cmd         panic button - removes Null, Stalkers and Verity
   10-HORROR-ON.cmd         puts them back
   8-HORROR-TEST-WORLD.cmd  test Null on a throwaway world (do this first!)

   5-BACKUP-WORLD.cmd       save a copy of the world now
   6-RESTORE-BACKUP.cmd     put an old copy back (undoable - backs up first)
   7-EXPORT-MCWORLD.cmd     make a .mcworld copy to send someone
   11-OPTIMIZE-STREAM.cmd   tune Minecraft for a steady 60 while live
   12-OPTIMIZE-MAX-FPS.cmd  rescue setting when the PC is struggling
   13-OPTIMIZE-QUALITY.cmd  push visuals on a strong PC

   1-CHECK-SETUP.cmd        what's installed, what's on, where everything is
   0-OPEN-DOWNLOAD-PAGES.cmd  re-open all the download pages
   2-INSTALL-ADDONS.cmd     re-install after downloading updates

----------------------------------------------------------
TWO THINGS TO KNOW
----------------------------------------------------------

  * Verity needs the "Beta APIs" world setting, so ACHIEVEMENTS ARE OFF in
    this world. The setup turns the setting on for you. No Minecraft world can
    have both Beta APIs and achievements - that's Minecraft, not this pack.

  * Null's latest release was built for an older Minecraft version. Run
    8-HORROR-TEST-WORLD.cmd on a throwaway world first to see if it still
    works. If it doesn't, 9-HORROR-OFF.cmd removes it in one click.


----------------------------------------------------------
FRIENDS
----------------------------------------------------------

Only you install anything. Friends join your world from their Friends list and
accept the download prompt - Minecraft sends them the addons. Your world has to
be open for them to join. Details: docs\MULTIPLAYER.md


----------------------------------------------------------
BACKUPS
----------------------------------------------------------

Every mode switch, horror toggle and restore takes an automatic backup into
backups\. Last 15 automatic ones kept; ones you make yourself kept forever.
Copy that folder to a USB stick or OneDrive now and then.


----------------------------------------------------------
WHEN SOMETHING GOES WRONG
----------------------------------------------------------

Run 1-CHECK-SETUP.cmd, then read docs\TROUBLESHOOTING.md.
Nine times out of ten it's one of these:
   - Minecraft was open while a script ran  -> close it, run the script again
   - Wrong world picked from the list       -> run it again, pick the right one
   - Vibrant Visuals off                    -> Settings -> Video -> Graphics Mode

Running slow? Run 11-OPTIMIZE-STREAM.cmd, then read docs\OPTIMIZATION.md.

Full addon list, links and versions:      docs\DOWNLOAD-LIST.md
What must never be combined, load order:  docs\COMPATIBILITY.md
